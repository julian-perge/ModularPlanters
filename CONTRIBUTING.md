# Contributing to Modular Planters

Contributions are welcome: bug fixes, compatibility fixes, guide corrections and code improvements.

I have a specific vision for the mod and what content fits it. Before working on new content or a balance change, please open an issue and talk it through first, so your time isn't spent on something that won't be merged.

## Issues

- Search the open and closed issues first. Your bug or idea may already be there.
- Use the bug report or feature request form. For bugs, a log link and steps to reproduce make the biggest difference.

## Pull requests

- Make one pull request per change. Separate fixes are easier to review and to revert.
- Link the issue the pull request fixes.
- Say how you tested it. At least run `./gradlew test` and `./gradlew runGameTestServer`, and check client-side changes in game and on a dedicated server.
- Check your spelling and grammar in text players see, such as the guide in `wiki/` and the lang entries.

[DEVELOPMENT.md](DEVELOPMENT.md) explains how to set up the project and run it locally.
