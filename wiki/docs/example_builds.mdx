The images use these colors:

- Orange: core
- Green: planter block
- Red: power block
- Brown: fertilizer block
- Blue: export block
- Purple: ME block (optional)
- Gray: frame block (does nothing)
- Pale translucent blue: glass

The glass canopy is decoration only. Glass is not part of the multiblock, and the built-in cloche needs no item.

These builds are examples only. Any shape works as long as every part touches the core or another part face to face, within the rules on the [Building Rules](building) page.
