# Any face-connected shape forms a multiblock

The multiblock is the Core plus every part connected to it face to face, directly or through other parts, with no fixed blueprint. Instead of checking a shape, the Core enforces a part cap (24 by default, in the server config, Frames included), the required parts (a Power, an Export and a Modular Planter Block), no second Core, and at most one ME block. The guide's example builds are only examples.

The cost is that the Core has to explain why it did not form, so its screen names the Problem.
