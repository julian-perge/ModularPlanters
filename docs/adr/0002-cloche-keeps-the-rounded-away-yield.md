# The built-in cloche keeps the rounded-away yield

ATE gives `max(1, round(count x fertilizer yield x upgrade yield x cloche yield))` for each drop, so a one-item drop at the default 1.1 cloche bonus rounds back to 1 and the bonus does nothing for single-item drops such as Mystical Agriculture essence. The owner decided the built-in cloche keeps the fraction that rounding throws away and pays one extra item each time it adds up to 1.

This is the mod's one deliberate buff. It never gives less than ATE and never more than the cloche's own share, and the extras are added after the post-harvest event so bonuses from other mods never apply to them.
